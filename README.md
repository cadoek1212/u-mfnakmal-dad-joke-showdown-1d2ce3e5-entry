## What it does

`main.ts` (Node 22) writes one dad joke — at most 200 characters — to `/output/entry.txt`:

> I named my dog Five Miles so I can tell people I walk Five Miles every day.

The program is fully deterministic: the same joke, byte for byte, on every run. It reads no input, uses no network, and nothing outside this repository affects the output.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
